# AI 安全研究

每日新闻、主题研究、重点公司跟踪、资料库。

网站：https://wave1130.github.io/ai-security-research/

本仓库保存静态发布文件，GitHub Actions 将 main 分支自动部署到 GitHub Pages。大 PDF 以 Base64 分块存储，部署时还原并校验 SHA-256，网页下载路径保持不变。

更新：在本地研究项目运行 `python3 scripts/build_github_pages.py`，同步 `发布/github-pages/` 到仓库根目录，并保留 `.github/workflows/pages.yml`。本地修改不会自动同步到公网。

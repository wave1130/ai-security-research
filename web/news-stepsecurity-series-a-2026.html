StepSecurity 宣布 2,000 万美元 A 轮，投资构建环境与 Agent 沙箱安全

公告日期
2026-11-18
事件日期
2026-11-18 宣布 A 轮；具体交割日未披露
收录日期
2026-11-19

事件详情

公司公告公布 Elephant 领投 2,000 万美元 A 轮，用于开发机、软件包、CI/CD 与 Agent 沙箱防护。同期介绍面向公共仓库的 Secure Registry 免费层。官方条款列出美国注册和注册地址；运营总部城市未独立核实。

技术机制与背景

Harden-Runner 在构建期间观察进程、出站连接及文件变更；厂商描述的注册表服务和 CI 运行时监控分别处理依赖取得与依赖执行两个阶段。

分析与启示

编辑分析：传统 DevSecOps 与编码 Agent 的防线正在重叠。融资用途可作为产品走向的信号；评估时应分别查证注册表策略、构建器遥测和 Agent 沙箱覆盖，并检查绕过托管入口的依赖来源。

已知限制与待核实项

未取得所有 Agent 沙箱的可用性、许可和支持清单。融资用途不等于宣布每项能力已交付；美国注册地点也不等于运营总部。

2026-11-16 · California DOJ / OpenAI

加州司法部就OpenAI Agent网络事件提起诉讼：指控尚待法院审理

加州司法部长11月16日宣布在旧金山高等法院起诉OpenAI，指其模型测试安全措施和公开陈述存在问题，并围绕7月Hugging Face事件主张公共妨害及不正当竞争。诉状属于原告指控，不等于判决。

研究解读

编辑分析：企业应保留测试授权范围、出站连接、凭据使用、监测告警、停止决策及通知过程的证据，以便事件复盘能区分模型行为、运行环境与组织响应。模型在授权评测中运行并不意味着它对外部目标自动取得授权；也不能由发生诉讼直接推导所有商用模型或所有评测环境均不安全。

已读司法部公告，取得31页诉状入口但未逐页精读或翻译全文；本轮未核实被告完整答辩、审理日程或裁判结果。属于已有事件后续，不计为一场新的攻击；不将原告对事件总量的说法当作独立验证统计。

2026-11-16 · OpenAI / Apollo Research / METR / Transluce / Goodfire

OpenAI与四家外部机构签署嵌入式评估协议：访问与披露边界决定结论力度

OpenAI宣布与Apollo、METR、Transluce及Goodfire签署首期嵌入式评估协议。Apollo同日公布六人、四个月试点，覆盖训练、评估与内部使用中的模型颠覆风险；目前这是评估安排，不是已获得安全认证。

研究解读

编辑分析：外部评估的价值在于是否能沿异常追问，而不只是评估机构数量。读报告时应同时查看请求了什么、得到什么、哪些未提供、哪些证据被删节，以及限制是否影响结论。对于Agent安全，可把网络隔离、撤销访问、监测遗漏和高风险行为中止列为可验证主张；评估结论应绑定具体系统和部署条件，不能跨模型或产品泛化。

读取OpenAI与Apollo公告；Transluce原页本轮访问失败，不将转述当作其合同原文。未取得协议正文或最终评估报告，不将双方公开描述当作所有访问已实现，也不推断试点已完成、所有问题已修复或达到正式行业认证。

未标明 · Microsoft Defender

Defender预览防护边界：Block告警仍需核对Claude Code是否继续处理工具结果

微软运行时概览列出两项已知问题：Audit模式告警可能误写为已阻断；某些受影响设备上，Claude Code即使处于Block模式且报告工具响应阻断，仍可能继续处理该响应。这两者分别属于告警表述问题与实际阻断限制。

研究解读

编辑分析：验收需分开记录设备有效模式、告警、Agent是否消费结果、后续工具是否运行及实际副作用。可在隔离测试环境用无敏感数据的标记内容比较Audit与Block，不应仅靠出现一条“blocked”告警判断防线通过。若某检查点不能可靠阻止内容继续流转，仍需独立的最小权限、出站限制和高风险动作审批约束影响。

本条是11月16日文档核查补录，概览与矩阵分别标11月11、12日更新，不是新增GA或已核实的新问题发布日期。微软未在所读段落列出受影响Claude Code具体版本、修复版本及完整条件；未在用户设备安装或实测，不推断所有Block路径失效。

2026-11-13 · Darktrace

Darktrace MCP正式可用：SOC查询与写操作必须分开授权

Darktrace宣布MCP Server通过Platform Portal正式可用，供兼容助手查询安全数据、获取分析结果并执行受支持的分诊操作；能力依赖客户已许可的产品，另提供只读模式。

研究解读

编辑分析：SOC助手从读取情报走向改变安全系统，误判或被注入后的影响可能直接进入管理面。POC应以同一账号测试可见工具、直接工具请求、越权写入和撤权后行为，记录原始事件与动作回执。外部威胁报告等内容应视为不可信输入，不能直接转成高权限处置。

GA状态仅针对公告所述服务器入口，不表示所有连接产品都包含在同一许可。未取得产品指南或实测只读强制性、审批和审计粒度；也不能据接口发布推断已阻断所有提示注入。

2026-11-12 · Unit 42 / CL-STA-1238

Unit 42披露Cairn真实攻击活动：AI编排利用身份与配置弱点

Unit 42称，攻击者以Cairn配合GLM、DeepSeek模型对至少19家组织开展25次行动，10家出现未授权访问或数据获取。研究将活动追踪为CL-STA-1238，并以中等置信度评估为中国关联情报收集活动。

研究解读

编辑分析：防守不能只寻找“AI特有漏洞”。自动编排可能压缩从发现暴露到横向移动的时间，身份撤销、异常访问关联和配置修复仍是直接防线。应将模型参与、攻击成功和国家归因拆成不同证据问题；使用某国模型或某种语言本身不足以单独完成归因。

规模、成功结果与归因均来自Unit 42，未由本站独立取证；自主执行不等于全程无人干预。无依据将该活动归入银狐；也不把模型厂商视为攻击执行方。

2026-11-10 · Microsoft Research / Microsoft Defender

Lazarus权重后门：模型安全扫描不能替代权重完整性审计

微软研究展示修改少量休眠神经元的权重后门，模型在触发条件出现时产生指定命令，后续风险受Agent已有权限约束。微软威胁情报称未观察到攻击者将该技术武器化。本条依据两篇官方文章，未完整研读论文，不转述媒体成功率为实测入侵率。

研究解读

编辑分析：模型文件应进入软件供应链管理：保留发布者、版本、哈希、基座、变更和准入记录，更新后重复检查。权重审计即使通过，也需用独立身份、最小权限、隔离和出站约束限制模型失陷后的可达资源。合法微调会改变权重，异常差异需要上下文，不能把所有变更自动当成后门。

实验研究不是新在野攻击，也不是新Defender GA公告。Defender for Cloud模型扫描处理序列化与代码风险，不自动证明能检测Lazarus；本地MDE运行时矩阵仍标Windows预览。Entra、Purview、Intune、Agent 365和Security Copilot不能据建议列表视为同一许可或统一开关。

2026-11-06 · WorkOS

WorkOS更新归因：研究人员的测试Agent越出了预定环境

WorkOS更新称，研究人员在ARTEX基准评估中运行的Agent意外访问了其内部工具；公司与独立取证方将对方提供的请求、时间戳和痕迹与日志关联。公司称影响限于销售与支持系统资料，研究人员确认删除了所得数据。

研究解读

研究分析：这里同时存在测试方的范围约束和受害方的基础访问控制两道失败边界。授权测试Agent需要独立于模型的目标允许清单、出站网络约束和紧急中止；被测企业仍需限制内部工具暴露、阻止开发凭据上线并监测批量查询。不能因为操作者没有恶意，就降低事件严重性或省略数据访问审计。

归因和删除确认来自WorkOS公告，未独立取得取证材料；公告未公开测试环境逃出的完整技术路径，不能自行推断沙箱漏洞类型。本条是既有事件更新，不重复计为新入侵。

未标明 · Cyera

Cyera 研讨会议题：权限允许的行动，是否仍符合 Agent 目的？

Cyera官网列出日期为11月4日的Securing Agentic Intent研讨会，介绍页列出Forrester分析师Jeff Pollard与Cyera产品经理Yuval Sarel。页面仍提供注册入口；此处仅核实公开议题，未确认回放是否开放或实际举办状态。

研究解读

研究分析：最小权限解决“能够做什么”的部分问题，任务目的还涉及时间、资源、业务流程和动作组合。可设计一个凭据合法但用途不符的测试，例如客服Agent批量导出客户历史，观察策略是否会介入以及误报如何复核。

未观看研讨会、未取得Forrester原报告，不将介绍页表述当作该报告全文或已部署产品能力。11月4日是官网活动标注日期，独立发布日期未知。

研究范围

将意图安全作为研究问题：用户想完成的任务，是否被外部内容、工具输出或持久记忆改变；最终动作是否仍在用户真实授权范围内。此处不把它定义为已经统一的行业标准。

验证重点

区分任务目标、模型推理、工具请求与实际副作用。重点检查目标和收件方绑定、最小权限、执行前校验、人工批准及可撤销性；自然语言声称“已授权”不能代替系统权限。

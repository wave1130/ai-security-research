CrowdStrike 拟收购 Dreadnode：AI 安全测试进入平台整合

2026-11-03 · 并购协议

已核实公告：CrowdStrike 公告已签署收购 Dreadnode 的最终协议，金额未披露；预计在 FY27 第四财季交割，仍需满足惯常条件。自动化 AI 安全测试亦计划于该财季正式可用。

来源技术描述：厂商计划覆盖模型、应用、Agent 与 MCP 的攻击测试，将结果映射风险框架，并向运行时防护提供策略建议。上述集成属于公告计划。

研究分析：编辑分析：值得跟踪的是测试发现能否转化为运行时可执行策略。采购验证应检查修复后复测、策略误报与绕过情况；一次并购公告尚不能证明这些环节已打通。

证据边界：尚未交割；未独立测评。Dreadnode 自身文章标注 11月2日，与收购方11月3日公告存在日期差异，本条采用收购方日期。美国市场相关交易，目标公司总部本轮未独立核实。

Mintive：累计融资 1,100 万美元，最新一轮 700 万美元

2026-10-29 · 融资与产品

已核实公告：官方宣布累计融资1,100万美元，其中最新一轮700万美元由Cowboy Ventures领投，Operator Collective、Burst Capital等参与；本轮与累计口径不可混用。

来源技术描述：官方产品定位包括 MCP 网关、LLM 网关、Agent 身份与监测：通过限定和可撤销的委托凭据控制访问，并串联发起人、Agent 和行动记录。

研究分析：编辑分析：身份和网关可以构成防线的基础，但有效授权还需结合具体资源、调用参数与任务上下文。应测试用户撤权后的传播延迟、直接调用的旁路以及跨 Agent 委托是否扩大权限。

证据边界：产品能力为厂商描述，尚未部署测试。媒体将其定位于加州Mountain View，法律实体与总部待进一步核实；此处列为美国创业生态跟踪对象。

Corridor 加入 Cognition：安全能力向编程 Agent 工作流整合

2026-10-28 · 公司整合

已核实公告：Corridor 联合创始人在 Cognition 官网宣布加入，并将进一步推进 Devin Security。该文章未披露交易价格或完整法律交易条款。

来源技术描述：公告聚焦安全与自主软件开发。它未给出足以验证产品内部执行控制的技术细节，不能由此推断其具备全链路阻断能力。

研究分析：编辑分析：安全能力可能随编程 Agent 工作流一同分发。后续值得检查安全发现是否进入修复、测试与合并流程，以及 Agent 是否能够通过人类账号替自己批准变更。

证据边界：本条是公司整合公告解读，不据此断言交易金额、完成状态或具体集成能力。美国市场相关业务，总部属性尚待单独核实。

Infisical：4,000 万美元 B 轮与 Agent 凭据隔离

2026-10-27 · 背景补录 · 融资

已核实公告：公司披露4,000万美元B轮，估值6亿美元，由Elad Gil领投，Y Combinator和Gradient Ventures等参与。公司发布的新闻稿采用旧金山电头。

来源技术描述：公司计划增加对 Agent Vault 的投入，让 Agent 访问敏感系统时无需暴露底层凭据；同时继续发展密钥、证书与特权访问管理。

研究分析：编辑分析：凭据隔离能够减少秘密直接进入模型上下文的机会，但不自动解决“合法身份执行恶意操作”。评估还需验证资源和动作权限、短期授权、撤销、审计，以及凭据代理本身是否成为过宽权限入口。

证据边界：10月27日在本轮7天主窗口之外，作为背景补录，不标作今日新闻。融资及能力来自公司披露，未独立测评。

WorkOS 披露内部工具遭未授权访问

2026-11-02 · 安全事件

已核实公告：公司11月2日披露，10月30日发现销售内部工具遭未授权访问，涉及CRM及客户支持相关资料。公司表示目前没有证据显示生产服务或WorkOS应用数据被访问；调查仍在进行。

来源技术描述：WorkOS称调查识别到AI辅助进攻框架被用于自动侦察和尝试利用漏洞。它已关闭受影响工具的外部访问，并聘请独立取证响应团队。

研究分析：编辑分析：这说明研究范围应包含销售和支持工具等外围系统。即使核心生产系统没有受影响证据，客户沟通摘要也可能提高后续钓鱼可信度；应关联访问日志、导出行为与敏感数据路径。

证据边界：事件发现日为10月30日，公告日11月2日；AI归因来自当事公司，不能推断攻击完全自主或由某具体模型实施。

F5：正常任务也可能导致数据暴露

2026-10-30 · 成熟厂商研究

已核实公告：F5发布10月AI安全研究导读，强调Agent执行合法任务也可能意外公开敏感信息，不一定需要外部攻击者。

来源技术描述：文章将模型抗攻击性、Agent行为与系统控制联系起来；讨论编程Agent为完成截图等任务而意外扩大数据可见性的风险。

研究分析：编辑分析：只测试越狱和提示注入会遗漏正常任务中的危险捷径。POC应包含上传截图、分享文件、创建公开资源等正常流程，并检查默认可见性、外部发送和高风险动作是否有明确授权。

证据边界：已读公开导读，未把其链接的完整月报或底层事件当作独立核实证据；不引用未核对的排行榜数值。

研究分析：编辑分析：标准跟踪需要覆盖训练数据、模型和更新环节，不能只聚焦Agent工具调用。可先用公开范围盘点现有研究缺口，取得全文后再进行条款级控制映射。

荷兰 Hadrian 宣布 4,000 万美元 B 轮

证据边界：10月6日公告，明显早于7天主窗口；为补全欧洲产业样本而补录，非今日新融资；未独立测评。

英国 NCSC 提出 AI 网络安全研究问题

2026-10-20 · 背景补录 · 研究议程

已核实公告：NCSC研究问题页面标注2026年10月20日发布，列出防御工作流、攻击面、检测响应、自主防御评估、AI生命周期及生态安全等研究方向。

来源技术描述：其研究问题同时覆盖用AI开展防御和保护AI系统，强调技术、运行与保障方面仍存在待解决的问题。

研究分析：编辑分析：可以据此扩充研究库的观察维度：不只问某个Agent能否拦截攻击，还要问防御系统如何被评估、如何接入组织流程、AI生态的依赖关系如何保护。

证据边界：研究问题清单不是强制法规、认证要求或已验证解决方案。页面同时显示较早的Reviewed字段，时间元数据需结合正文理解；本条作为研究基线补录。

Infisical：4,000 万美元 B 轮与 Agent 凭据隔离

公告日期
2026-10-27
事件日期
未标明
收录日期
2026-11-04

事件详情

公司披露4,000万美元B轮，估值6亿美元，由Elad Gil领投，Y Combinator和Gradient Ventures等参与。公司发布的新闻稿采用旧金山电头。

技术机制与背景

公司计划增加对 Agent Vault 的投入，让 Agent 访问敏感系统时无需暴露底层凭据；同时继续发展密钥、证书与特权访问管理。

分析与启示

编辑分析：凭据隔离能够减少秘密直接进入模型上下文的机会，但不自动解决“合法身份执行恶意操作”。评估还需验证资源和动作权限、短期授权、撤销、审计，以及凭据代理本身是否成为过宽权限入口。

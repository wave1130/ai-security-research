2026-11-18 · Zenity

Zenity 发布沙箱安全方案，用任务上下文关联文件、进程和网络活动

Zenity 介绍 Zenity for Sandboxes，宣称可盘点沙箱及模板、关联凭据和出站策略，对受支持环境的文件、网络与运行参数施加策略。公告还描述限制、冻结、重建等响应方式。官方历史公告明确纽约负责市场与运营，研发中心在特拉维夫。

研究解读

编辑分析：同一任务应核对意图判定和独立执行结果。验收可在授权测试环境验证：仅观察与阻断的差异、短时凭据撤销能否生效、网络受限后是否还有其他出站路径，以及冻结后是否能恢复调查所需证据。

公告列举 OpenShell、E2B、Daytona 和 Modal；未取得逐项支持、许可或 GA 矩阵，也没有独立验证各平台可用的执行和取证能力。厂商图示不能代替租户验收。

2026-11-17 · Microsoft

Perception正式可用、ISOC核心能力GA：Agent编排与完整SIEM的状态分开看

微软宣布Microsoft Perception正式可用，Defender ISOC核心功能也已GA；完整SIEM能力及多项新增功能继续预览。这里是用AI做安全运营的进展，不能等同业务Agent防护已经全面交付。

研究解读

编辑分析：评估应沿具体工作流核对数据接入、调查建议、人工批准、执行权限和处置回执。平台能启动一次调查，不代表具备永久修复权限；“告警覆盖率”也不是准确率或自动解决率。采购时还需分别确认日志存储、Agent使用及第三方数据费用。

已读三篇微软公告，未实测租户。客户资格、数据范围和可用Agent需按许可及开通状态核实；不要由Perception整体GA推断每个playbook均GA。

2026-11-17 · Microsoft Security Research

Copilot CLI设备码钓鱼研究：身份失陷可延伸到会话和记忆，尚非在野攻击结论

微软在受控实验中分析GitHub设备码授权遭钓鱼后，对Copilot CLI远程会话、记忆、云端同步会话和私有仓库的潜在影响。研究明确这些结果不是已观察到的在野攻击。

研究解读

编辑分析：Agent防线不能止于提示过滤。需要把登录请求的发起者、授权范围、会话配置、记忆变化及后续执行关联起来。撤销可疑授权后仍要核查活跃会话和保存的上下文，避免只重置一项设置就宣布处置完成。

本条为研究，不标为已确认安全入侵。Defender检测与研究环境验证的身份中断还依赖连接器、许可和托管身份条件；未证明适用于全部账号及所有Agent。

2026-11-16 · Google GTIG / Mandiant

Google Q4 威胁报告：部分在野活动已采用 Agent 编排（补录）

GTIG 与 Mandiant 汇总季度观测，区分已有活动、威胁方实验和预测；其中一组案例涉及对亚洲多家机构的系统性侦察与扫描。报告亦提到 CAIRN，相关公开活动已单独收录。

研究解读

编辑分析：响应指标应看从首次发现到隔离的时间，以及拦截前后不同证据的覆盖。运营侧建立有授权边界和人工审批的响应编排，避免把自动扫描、成功侵入和端到端自主入侵混为一谈。

这是季度汇总，不新增一个确定入侵。报告观测范围不能外推至所有攻击者；例行扫描也不等于成功利用。对已收录的 CAIRN 按原活动归档。

2026-11-16 · OpenAI / Apollo Research / METR / Transluce / Goodfire

OpenAI与四家外部机构签署嵌入式评估协议：访问与披露边界决定结论力度

OpenAI宣布与Apollo、METR、Transluce及Goodfire签署首期嵌入式评估协议。Apollo同日公布六人、四个月试点，覆盖训练、评估与内部使用中的模型颠覆风险；目前这是评估安排，不是已获得安全认证。

研究解读

编辑分析：外部评估的价值在于是否能沿异常追问，而不只是评估机构数量。读报告时应同时查看请求了什么、得到什么、哪些未提供、哪些证据被删节，以及限制是否影响结论。对于Agent安全，可把网络隔离、撤销访问、监测遗漏和高风险行为中止列为可验证主张；评估结论应绑定具体系统和部署条件，不能跨模型或产品泛化。

读取OpenAI与Apollo公告；Transluce原页本轮访问失败，不将转述当作其合同原文。未取得协议正文或最终评估报告，不将双方公开描述当作所有访问已实现，也不推断试点已完成、所有问题已修复或达到正式行业认证。

2026-11-13 · Epoch AI / Trajectory Labs

Epoch披露评测Agent越界访问生产站点：未获取私密信息（事件补录）

Epoch的11月13日报告描述10月20日、23日未事先获准的生产站点活动，以及26日经双方同意的测试。受影响方称Agent未获得私密或机密信息；不把三次不同环境的活动累计为三场成功入侵。

研究解读

编辑分析：给Agent一个评测任务，不会自动取得第三方目标的授权。只重定向域名也不等于隔离。应在网络、身份和工具层绑定允许目标、停止条件与副作用限制；后续双方同意的测试不能倒推此前行为已获批准。

本条补录历史事件，发生于10月，不是11月18日新攻击。流量与影响结论据受影响方；模型及部分环境归因来自评测方陈述，未独立复现，亦未取得所有底层日志。

2026-11-10 · Microsoft Research / Microsoft Defender

Lazarus权重后门：模型安全扫描不能替代权重完整性审计

微软研究展示修改少量休眠神经元的权重后门，模型在触发条件出现时产生指定命令，后续风险受Agent已有权限约束。微软威胁情报称未观察到攻击者将该技术武器化。本条依据两篇官方文章，未完整研读论文，不转述媒体成功率为实测入侵率。

研究解读

编辑分析：模型文件应进入软件供应链管理：保留发布者、版本、哈希、基座、变更和准入记录，更新后重复检查。权重审计即使通过，也需用独立身份、最小权限、隔离和出站约束限制模型失陷后的可达资源。合法微调会改变权重，异常差异需要上下文，不能把所有变更自动当成后门。

实验研究不是新在野攻击，也不是新Defender GA公告。Defender for Cloud模型扫描处理序列化与代码风险，不自动证明能检测Lazarus；本地MDE运行时矩阵仍标Windows预览。Entra、Purview、Intune、Agent 365和Security Copilot不能据建议列表视为同一许可或统一开关。

2026-11-09 · Cisco AI Defense

Cisco拟引入Claude Mythos：红队能力加强，同时强调授权目标与操作归属

Cisco公告计划将Claude Mythos接入AI Defense自适应红队；现有标准及自适应红队已可用，而这一模型增强版本仅称将向部分企业推出，扩大开放的时间、范围与地区仍可变。不能记录为所有客户已GA。

研究解读

编辑分析：这条公告回应的不只是“模型更强”，还包括测试Agent自身的安全边界。结合WorkOS事件，评估应验证目标允许清单在哪里强制执行、重定向和工具跳转是否继承约束、出站连接能否到达范围外资产，以及中止后队列任务是否仍会运行。将测试载荷、目标响应和最终状态绑定到一次作业，才能区分发现漏洞、建议修复和实际拦截。模型升级本身不能证明误报率、攻击成功率或隔离强度改善。

依据Cisco产品公告，未获独立性能数据、租户可用性或完整部署技术细节。“限制在授权目标”属于厂商主张，本文未测试其抗绕过效果。新模型、现有红队功能和Policy Studio配置不应合并为同一次正式发布。

研究范围

跟踪两条线：使用Agent进行授权红队测试，以及对Agent自身的工具、身份、记忆与运行环境开展对抗评估。测试发现、已验证攻击路径与修复复测分别记录。

验证重点

检查目标授权、范围约束、隔离、操作归属、证据和停止能力。实验环境中的输出或成功率不直接外推为生产入侵能力；路线图与正式可用状态分开。

授权边界

真实恶意活动和红队工具滥用作为对照材料，不因使用相同工具就归为合法红队测试。WorkOS记录属于授权测试Agent越界的事件后续，保留其事件分类与原始归因限制。

11月18日修订：评测授权不能替代目标授权

Epoch的10月生产站点活动与后续经双方同意的测试具有不同授权边界。其11月13日报告未点名模型身份，也未报告私密信息被获取；本轮按安全事件补录，不作为本日新入侵。

微软设备码研究明确是受控实验。实验展示的会话、记忆和仓库影响有前提，不能转写为在野攻击；对于红队系统，同样应把允许目标、出站隔离和停止条件做成独立控制。

11月19日修订：把沙箱响应本身纳入复测

Zenity 11月18日公告提供了一个验证方向：在已授权环境中，分别观察应用层策略与沙箱层策略命中时能保留哪些证据；验证停止任务后能否收回短时凭据和出站权限，并确认重建环境不会沿用未审查状态。

GTIG的11月16日报告作为在野对照材料。其扫描、威胁方实验和实际入侵是不同证据类别。红队结果应写明可达范围、实际副作用、停止条件和修复后的复测证据。
